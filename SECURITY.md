# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use a private
[GitHub Security Advisory](https://github.com/pravennn08/semaphore-sdk/security/advisories/new)
for this repository. Include the affected version, a description of the impact,
and a minimal reproduction when it is safe to do so.

Never include Semaphore API keys, phone numbers, OTPs, message bodies, or other
personal data in a report. Replace them with clearly fake values. If a secret
has been exposed, revoke or rotate it in Semaphore before submitting the report.

## Supported versions

The latest published release receives security fixes. Older releases may not
receive fixes; upgrade to the newest version before reporting a problem when
possible.

## Scope

This policy covers the `semaphore-sdk` package and this repository's code,
build, and release configuration. Provider-side account security, API outages,
and message delivery issues should be reported to Semaphore through its own
support channels.
